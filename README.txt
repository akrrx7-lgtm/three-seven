THREE SEVEN v1.12 更新手順

1. Firebaseコンソール → Realtime Database → ルール。
2. 現在のルールをバックアップし、同梱の firebase-rules.json の全内容で置き換え、「公開」。
3. GitHub Pages の既存リポジトリ three-seven の index.html を同梱の index.html に置き換えてコミット。
4. 公開ページを再読み込みして V1.12 を確認。2台とも最新版を使用。
5. オンライン対戦で各自の名前（1～16文字）を入力し、ランダムマッチングを押す。
6. 対戦、勝敗、再戦、キャンセル、フレンド対戦、再読み込み後の名前・成績保持を確認。

Firebase接続情報は既存プロジェクトに設定済み。再登録不要。
成績はこのブラウザのlocalStorageに保存。旧版の対戦は遡及集計しない。名前変更でも成績は引き継ぐ。別端末・別ブラウザとの同期はない。通信中断で結果未確定の試合は集計外。
ランダム検索の待ち時間は約90秒。待機枠は1件、対戦開始後は別の組が検索できる。
既存のフレンド対戦ルールは維持し、名前・待機枠を追加。実際のFirebaseルール検証とオンライン対戦は未実施。サーバー側の完全な不正対策・使用済み部屋の定期削除は未実装。
